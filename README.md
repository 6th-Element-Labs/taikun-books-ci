# Taikun Books CI

Public verification-only CI for `6th-Element-Labs/taikun-books` (private canonical source).

- `main` contains the trusted workflow and this notice.
- Disposable `ci/<source-sha>` refs carry source-only snapshots.
- Every run verifies both the canonical commit marker and the exact Git tree.
- Source snapshots are public while present. Deleting a ref is cleanup, not erasure.
- No company database, source document, email, token, credential, or operational evidence belongs here.
- This repository has no authority over product completion or deployment.
